# Provelume Windows icon

`provelume.svg` is the public, versioned source for the application identity. Run
`python scripts/generate_windows_icon.py --check` to verify the checked-in multi-resolution ICO,
or omit `--check` to reproduce it. The generator uses only the Python standard library and makes
no network request.

The icon supplements visible and accessible product labels. It is never the only representation
of an action, status or application identity.
