# Universal representation threat-model delta

This delta applies only to `0.10/S01`. The existing local, clean-room, immutable-Original and
loopback security boundaries continue to apply.

| Threat | S01 control | Residual boundary |
| --- | --- | --- |
| A preserved type is presented as extractable or searchable | Six independent registry rows; Preserve grants no higher operation | A future profile must qualify every higher operation separately |
| Path traversal or cross-bundle output substitution | NFC-normalized relative Windows-safe paths, bundle-specific ceilings, exact representation-root binding and safe Instance resolution | Host filesystem integrity remains an operator responsibility |
| Case or file/directory collision changes portable meaning | Sorted unique path set plus case-folded and node-kind collision rejection | Filesystem Unicode behavior outside the closed portable rules is unsupported |
| Decompression or derived-output exhaustion | Closed count, per-file, total-byte and expansion ceilings | Future decoders need stricter pixel/duration/process limits in their own slice |
| Tampered bundle/output is shown or imported | Strict schema, canonical Version/Original lookup, recipe/output/representation fingerprints and deep hash/size validation | S01 authenticates internal consistency, not an external publisher |
| Anchor escapes its evidence | Every anchor repeats exact Version and representation IDs; target shapes fail closed | Reserved anchor kinds declare no format support |
| Correction overwrites authority | Corrections are reversible checksum-bound annotations on derived state | User intent and semantic correctness remain review decisions |
| Removal destroys lineage | A derived removal receipt retains the exact bundle fingerprint and provenance | Rebuild still requires the pinned recipe/component and regenerated bytes |
| Legacy migration corrupts Lectio data | View-only packaged compatibility mapping; no eager migration or canonical field | Invalid legacy state continues to be handled by its original contract |
| Capability inspection triggers network or execution | Packaged registry plus local configuration/component evidence; reads state `network_used: false` | Installing an optional component is an explicit external operator action |
| AI path appears through a generic “enrich” operation | `ai_enrich` is forced to unavailable with `not_implemented`; bundle invariant `ai_used: false` | A later AI release needs a separate threat model and authorization decision |

The Browser renders only identifiers, states, closed reasons, component names and counts. It does
not render representation output, active markup or provider content. Service, CLI and API reads do
not create, repair, remove or rebuild a representation.

Backup and portable import validate the entire staged Instance before commit. A representation
finding blocks installation; no failure, cancellation or timeout is converted to success.
