`personal-qualify` is an explicit diagnostic command for a **new synthetic target**.
It uses the actual setup coordinator, scheduler, ingestion, search, templates,
Original downloads, consultation recorder, backup verifier and restore/rebuild.
It records the embedded build identity without asserting artifact provenance.
No existing personal Instance or input directory is selected.

is not an installed, browser, platform or human PASS. The command reports those
rows explicitly as NOT_RUN. Browser/installer/offline jobs must record their own
exact source, executable/artifact hashes, environment and original outcomes.
