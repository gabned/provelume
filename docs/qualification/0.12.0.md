The [full S09 ledger](https://github.com/gabned/provelume/pull/336#issuecomment-6099065777)
retains earlier failures, including the Linux warm-first failure before the fixed
100 ms model-read polling configuration, subsequent 57544c4 concurrent-Capture
timing failures, and a historical container failure whose internal reason was not
captured. The later scheduler snapshot and early OCR-cancellation corrections
require complete new candidate qualification. Later successful measurements never rewrite them.

Windows executables remain unsigned previews. Byte-identical independent rebuild
claims cover Python wheel/sdist on separate runners of the same provider; they do
not cover deterministic frozen executables or independent providers. The immutable
workflow wheelhouse is not a reviewed transitive repository lock. Model weights
are explicitly acquired or imported and stay outside application/Instance artifacts.

The older 0.10.1 schema-1 updater cannot read the newer publication manifest. Use
the complete 0.12 installation kit for this one manual transition; published 0.11
assets are immutable. The new reader preserves schema-1 compatibility and requires
the actual publication receipt/readiness for schema-2 updates.
