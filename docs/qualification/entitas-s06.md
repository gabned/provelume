contracts and separately tests their composition. All inputs and model responses
are synthetic. External socket connections and DNS attempts are denied in these
journeys; native loopback/event-loop wakeups remain available on Windows.

  retains existing Project/Collection identities, creates an evidence-bound Claim,

  across explicit migration, create an actual governed synthetic producer job and
  immutable receipt, grant manual Source-scoped review separately, disable AI,
  approve once, and retain history after draft/base-result disposal, a later manual
  edit and Document Version change. Backup/restore and both portable choices retain
  canonical/review/immutable scheduler receipt bytes and accounting. The existing
  replacement contract deliberately increments the execution generation, keeps AI
  Off and marks the retained job restored; it does not rewrite accounting or
  silently replay inference. Foreign AI-bearing import is refused with verified
