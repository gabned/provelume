# Iudicium reviewed classification application

S03 owner: #361, parent #349. This describes the implementation and required
qualification, not acceptance of a candidate or release. S01 and full S02 were
accepted before S03 activation; S04 and S05 remain ordered successors.

The existing Action Center opens a recorded assessment. Its classification review
link opens the existing local domain-review boundary in either interface. The
policy screen exposes current destinations, Source/path scope, task languages,
expiry of at most ninety days, maximum application count and four autonomy modes.
Creating or broadening a policy requires a fresh explicit confirmation and
independently configured classification review capability. The receipt retains
the reviewed scope and bounded history; destination names remain untrusted data.

For a manual application, inspect the selected source, explicitly choose current
canonical destinations and acknowledge independent review. The fresh preview
shows before/after, metadata-only impact, reversibility and unknown confidence.
Confirmation binds the current Source/Version/Original, placement, complete target
inventory, model-profile identity, policies, quality revision and host capability.
It recollects under the existing lifecycle and AI journal locks and commits the
classification, usage count, consumed-assessment index, history and receipt in one
registered atomic review transaction. Navigation and inspection do not authorize
application, inference, consent renewal or another execution owner.

Undo selects a committed application receipt and requires fresh local confirmation.
It checks the current Version and exact classification preimage, then restores
the exact previous classification bytes or the initial unclassified state.
It preserves Originals, Versions, provenance history, accounting and receipts.
Later classification changes block undo. Policy revocation/expiry, AI Off and
private-body removal do not remove the independent remedial review path.
An assessment remains consumed after undo; budget is not refunded or silently
replayed. A lost or changed consumption index blocks further policy use.

The classification-only removal extends the existing registered atomic product
transaction format. Existing write-only transactions retain schema 1; explicit
removal uses schema 2 and a retained preimage plus atomic rename marker. This
product format is unrelated to deferred Agent Protocol Lifecycle v2. Recovery
restores only the transaction's own removal and refuses foreign later writes.

Real classifier quality remains `NOT_EVALUATED`, confidence null. Synthetic tests
verify mechanics only. A controlled-automatic policy request supplies no current
automatic permission; both host authority and provider deny it. Later real S05
evidence must change the quality revision and require a new policy review before
any automatic permission can be considered. No existing pending rule is promoted
by a confidence value, test fixture or historical attestation.

Machine qualification covers atomic interruption/rollback/recovery, exact undo,
destination role swaps inside the reviewed scope, denial of role changes outside
that scope and preservation of unchanged outside-scope destinations,
receipt replay, consumed assessment retention, expiry/budget/scope/current-policy
denials, changed source and quality evidence, both ordinary interfaces, local
Origin/nonce controls, pure reads and preservation of an existing execution owner.
Use full unchanged-candidate native tests/Ruff/diff before publication, then all
permanent exact-source workflow attempts/jobs and reviews, effect binding, fresh
preflight, normal expected-head merge, actual parents/tree and all post gates.
GitHub receipts carry actual results; no old source/host result qualifies a new one.

Human Windows/accessibility/catalog observations remain `NOT_RUN`/`UNVERIFIED`;
independent label review remains `NOT_REVIEWED`. The maintainer explicitly made
these omissions nonblocking in #349 comment6186153379. They confer no runtime
consent, classifier quality, automatic authority or Protocol waiver. Final
