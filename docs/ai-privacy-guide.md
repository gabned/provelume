# AI & Privacy setup

Open Settings → AI & Privacy. AI starts Off, and capture, search and document
reading remain available without it. The Local Recommended choice describes the
locked candidate; it does not mean the S09 promotion has happened.

1. Choose a mode and limits, then save. This disables any previously enabled
   execution session. External and Hybrid require the supported compatible HTTPS
   endpoint and explicit fallback order. A credential reference is not a secret,
   proof of availability or authorization to send.
2. For local setup, select the explicitly obtained locked runtime directory and
   verify it. Import the matching public model file, or explicitly acquire it after
   reviewing the displayed size and licenses. No page opening downloads anything.
3. Verify the model, run its bounded self-test, and activate only when the host can
   establish the required locality evidence. Missing or incompatible bytes fail
   closed. Review the operation status and refresh to observe actual completion;
   a cancellation request does not mean the operation has stopped.
4. Enable the session separately. Preview the public synthetic test, inspect the
   redacted payload, route and limits, and approve that exact test. Creating the
   job still does not execute it. Use Operations → AI to dispatch or cancel it.
5. Read its receipt and accounting. Unknown usage is not zero. Ambiguous sends
   cannot be retried automatically. Reconciliation requires separate evidence of
   termination and acknowledgement of duplicate execution/cost risk, and does not
   rerun the test.

In a Document Viewer, AI preview selects an existing text representation and page
plus a character interval (zero-based start, excluded end). Its coverage describes
that representation, not the Original or all other representations. Redaction
detects the documented ASCII email pattern and exact configured literals only;
it is not anonymization. The preview is private and cannot execute a document
task. This slice does not add summaries, key points or saved AI output.

Restarting, restoring or changing configuration requires fresh authorization.
Session-only runtime paths, weights, credentials and self-test evidence are not
restored from the portable configuration. Disable before deactivation/removal;
the lifecycle offers only applicable actions and checks them again on the server.

Current limits: bare Windows local dispatch lacks independently enforced locality
proof; external profiles lack live qualification and a defensible price quote;
arbitrary BYOM is unsupported. Controlled synthetic transports and independently
observed native CI runs are separate evidence, not live provider certification.
