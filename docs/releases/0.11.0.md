## Defaults, upgrades and recovery

After S09 qualification, release preparation selects the Cura presentation for
fresh installations and missing preference files, using the existing schema-3
interface field. It does not invent a user-choice receipt at first creation.
Existing schema-1/2 preferences and explicit Current/Preview selections are loaded
and preserved through upgrade. Current remains a presentation-only rollback;
legacy presentation removal is later bounded work.

Explicit appearance/all-preferences reset previews the new default presentation,
System language and System appearance before confirmation. Cancellation changes
nothing. Import remains bounded and secret-free; Undo is a fresh forward transaction.
Knowledge, Originals, Sources, credentials, job history, backups, pairing/outbox
and the chosen Instance remain outside preference reset.

Close-to-tray and login startup remain independent. First close permits Cancel;
Exit stops the runtime and removes the icon. Tray status comes from Scheduler/
Action Center, includes only bounded content-free counts and opens existing controls.
System/Light/Dark is applied before rendering; native high contrast retains the
host palette. Windows artifacts remain unsigned.

## Official preview publication

Only the permanent release workflow may tag the reviewed main candidate and publish
its independently qualified bundle. Version/tag/source/channel must agree.
Normal CI and development installers do not publish. Independent runner rebuild
equivalence applies to the wheel/sdist; no full Windows reproducibility claim is made.

The publisher reads back every unchanged core payload, creates the separate receipt
from the actual publication event, wraps unchanged bytes in the exact-version
installation kit, attests receipt/kit and verifies the complete public set before
publishing and observing the readiness marker. A release object or marker alone is
insufficient. Recovery retains the same qualified bundle and never overwrites assets,
moves tags or rebuilds payloads. Follow [offline installation](../publication-installation.md)
and [release verification](../release-verification.md).
The campaign closes only after this independent post-publication observation.

No stable promotion, signing, full background agent, AI authority, future network-
folder tray, unrelated dependency update or 0.12 activation belongs to Cura.
#167's accepted later network-folder/full tray folder guide remains #259 (0.20).
