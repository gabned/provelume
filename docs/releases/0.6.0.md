## Product outcome

`0.6.0` makes one local Instance explicitly versioned, recoverable, portable and directly
navigable as a deterministic Markdown filesystem library while keeping canonical JSON, exact
acquired Originals, Versions and provenance authoritative. It delivers the five bounded slices
from issue #95:

- a schema-2 Instance manifest, forward-only N-1 migration, deep preflight, verified automatic
  backup, staged restore and explicit interrupted-operation recovery;
- stable parent-linked Area/Subarea, Project and Collection identities with one primary library
  classification, ordered secondary associations and preserved provenance;
- a deterministic staged `library/` projection with README indexes, Area/Project primary paths,
  generated Collection/Source/date/type views and safe rendered/raw/Original Viewer modes;
- distinct archive, remove-from-library, recoverable trash, identity-preserving restoration and
  explicitly authorized permanent purge with honest Source/backup/replica boundaries;
- deterministic hash-manifested portable export and staged replacement import with strict
  Windows/Linux path validation, explicit include/rebuild derived-state policy, verified rollback
  and crash recovery.

## Compatibility and authority boundary

Opening a valid public `0.5.1` schema-1 Instance performs the registered schema-1 to schema-2
migration only after deep canonical/Original preflight and a separately verified automatic backup.
Migration preserves the Instance ID, canonical records and Original bytes, writes a deterministic
receipt and fails visibly on unknown future schemas. Validation itself never migrates.

The Markdown library and SQLite search index remain disposable derived views. Default portable
import rebuilds both from canonical state; explicit `include` mode deeply verifies every library
file and compares every indexed identity, filter field, title and content value with current
canonical/derived records before accepting the bytes. Portable import replaces an existing target
Instance rather than attempting multi-master merge.

Configured Source, Drop and managed-copy working folders remain outside backup/export claims unless
their bytes were already acquired as canonical Originals. Purge authority is limited to the live
Instance and never claims erasure from Sources, backups or replicas. The local Knowledge Browser
remains a single-user loopback application without accounts, LAN or Internet serving.

## Release evidence

The reviewed release candidate must pass:

- Ruff and the full test suite on Ubuntu and Windows;
- trusted-base change control plus clean-room and repository-hygiene checks;
- deterministic wheel and source-distribution comparison across independent clean source copies;
- offline rebuild, release-bundle verification, checksums, CycloneDX SBOM and attestations;
- Windows x64 installer build and a real upgrade from the immutable public `0.5.1` installer,
  proving stable AppId, schema-1 to schema-2 migration, exact Instance/settings preservation,
  loopback startup, Unicode/default paths and uninstall behavior;
- exact tag, package, embedded identity, public commit and preview-channel agreement;
- deterministic portable export/import and library rebuild, hostile bundle rejection, rollback and
  interrupted-operation recovery without network or AI capability.

The public baseline installer is `Provelume-Setup-0.5.1-x64.exe`, size `18,206,254` bytes and
SHA-256 `642de2931dc6fbc7f1a58fd490b73c45cef72719bc75c690713076f9bddf268b` from
`v0.5.1@b3156617dc2ce9c97cd32ee105c18634cd4b9776`.

## Explicit exclusions

This preview does not include autonomous classification, multi-master synchronization, a watcher,
connector or network Source, OCR, AI, semantic/vector search, cloud storage, accounts/billing,
Authenticode, unattended update application or Agent Development Protocol changes. The Windows
installer remains unsigned and every update installation remains explicitly user-confirmed.
