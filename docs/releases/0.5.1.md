# Provelume Core 0.5.1 release plan

This correction release consolidates the public `0.5.0` durable-intake preview through issue #80.
Implementation and release preparation are complete. This document does not itself create a tag
or publish assets; those privileged actions remain restricted to the permanent release workflow
operating on the reviewed `main` result.

## Correction outcome

`0.5.1` adds no new product capability and makes no mandatory canonical Instance migration. It
delivers the three bounded correction slices from issue #80:

- loopback-only serving, trusted Host enforcement, restrictive private-response headers and a
  disabled interactive documentation endpoint until it has an offline-safe contract;
- preserved EN/IT navigation state, keyboard-visible focus, a skip link, main landmark and current
  navigation state;
- incremental full-text refresh of only changed Documents when schema-2 derived metadata, the
  Document-to-Version map and physical row count agree;
- complete-rebuild fallback for missing, legacy, malformed or inconsistent derived state, with
  restoration of the previous database/metadata pair if replacement fails;
- bounded weekly dependency-update proposals with no release authority;
- explicit latest-preview security, local-serving and unsigned-installer limits;
- a measured maintainability pressure map plus inactive operation-pagination and decomposition
  follow-ups.

## Compatibility and authority boundary

Canonical JSON, content-addressed Originals, ingestion records, operation history, folder settings,
document bundles, duplicate evidence and assurance reports retain their `0.5.0` contracts. Search
metadata schema 2 and `search.sqlite3` remain disposable derived state. Existing schema-1 search
metadata is rebuilt transparently from canonical Documents and extracted text.

The local Knowledge Browser remains a single-user loopback application without accounts, LAN or
Internet serving. The Windows preview remains unsigned. Update checks remain disabled by default,
send no Instance content, never apply an installer silently and require explicit user confirmation.

## Release evidence

The reviewed release candidate must pass:

- Ruff and the full test suite on Ubuntu and Windows;
- trusted-base change control plus clean-room and repository-hygiene checks;
- deterministic wheel and source-distribution comparison across independent clean source copies;
- offline rebuild, release-bundle verification, checksums, CycloneDX SBOM and attestations;
- Windows x64 installer build and a real upgrade from the immutable public `0.5.0` installer with
  stable AppId, Instance/settings preservation, loopback startup, Unicode/default paths and
  uninstall evidence;
- exact tag, package, embedded identity, public commit and preview-channel agreement.

The public baseline installer is `Provelume-Setup-0.5.0-x64.exe`, size `18,193,123` bytes and
SHA-256 `c604de1006c6f86a52bf61ca54fe6371e0889f728eb89f25e38776165254ecab` from
`v0.5.0@89c6b7c783e385c4e978cc2ae6bf602012aab77e`.

## Explicit exclusions

This patch does not include hierarchy, Markdown library projection, Instance migration/backup/
restore/import/export, a watcher, connector, OCR, AI, semantic search, canonical storage changes,
Authenticode, unattended update application, accounts, billing, Cloud or Agent Development
Protocol changes. `0.6.0` remains the next non-activated forecast.
