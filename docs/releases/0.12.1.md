## Finite delivered scope

- Model acquisition refreshes progress and available actions without discarding
  unsaved fields, enabling AI or repeating operations; errors, connection loss
  and cancellation stay explicit.
- Cura Management provides direct AI & Privacy, AI operations, preferences and
  notifications. Document synthesis retains the originating search context.
- Cura is labelled as the standard interface. Upgrades with ambiguous inherited
  choices offer a reversible selection; an explicit previous-interface choice
  remains respected.
- Local AI request admission tolerates the verified idle-cleanup race without
  retrying generation. Capture overlaps independent journal I/O while retaining
  fsync, integrity, ordered replacement and recovery barriers.
- Linux atomic target checks avoid a second Python metadata traversal through a
  kernel no-symlink lookup after all fresh component observations. Parent swaps
  are rejected; unsupported hosts retain the original resolver. No path observation
  is cached and no flush, journal limit or acknowledgement barrier is removed.
- Windows model admission uses the system SHA-256 implementation for the same
  complete-file digest, with unchanged MiB read/cancellation/deadline boundaries,
  header/size/identity checks and limits. Hash state is per read and always closed;
  unsupported platform APIs retain the original SHA-256 implementation.
- Native failure diagnostics retain only closed causes/phases/reasons and numeric
  native/exit codes in existing durable receipts. EOF observation and imposed
  cleanup termination are distinguished; no prompt, output, stderr or private
  exception text is retained.
- The Windows tray distinguishes the browser application from the local service
  panel; controls, appearance and seven-language/high-DPI layout remain usable.
- The release pipeline qualifies ordinary AI on the exact Windows Setup later
  assembled, with the original 12 controls and ordered 32-case first-attempt
  corpus, and retains every outcome and all public upgrade baselines.

No model, corpus, classification, RAG, connector/provider, autonomy, inference
limit, consent, accounting, isolation, integrity or durability policy changes in
this release.

## Finding AI and choosing the interface

1. Open **Management → AI & Privacy**. Explicitly permit network access for a
   download, or import offline. Follow progress and use Cancel when needed.
   Refresh does not restart acquisition or enable AI.
2. Verify/test the model and explicitly enable local AI for the session.
   Restart leaves AI off.
3. Open a document from **Knowledge** or **Search**, select **Document synthesis**,
   inspect the exact Version/text and private preview, and explicitly consent.
   Results, references and receipts are in **Management → AI operations**.
   Returning to Search preserves its filters.
4. Use **Shell settings → Interface** or the guided notice to select
   **Cura · standard interface**. Select **Previous interface** to roll back.
   Instance, knowledge, language, theme and AI/network permissions are retained.

In Italian, **Apri Provelume** opens the browser application and
**Pannello locale** opens the native service panel. High-DPI actions stack and the
lower controls remain reachable through scrolling.
