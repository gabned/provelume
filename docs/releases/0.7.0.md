# Provelume Core 0.7.0 — Vinculum release plan

`Vinculum` is the first Provelume preview that can acquire one explicitly requested web URL
through a provider-independent connector boundary. It keeps network access visible and bounded,
preserves the exact acquired bytes as an immutable Original and records the connector, Source and
Acquisition provenance used to obtain them.

This remains a **prerelease**. Acquisition is manual: `0.7.0` does not watch folders, refresh in
the background, run OCR or ask an AI system to classify content. Those capabilities remain in
later forecast releases.

## What 0.7.0 enables

- Define provider-independent connector types through versioned capability and conformance
  manifests instead of coupling canonical knowledge to one provider.
- Keep `ConnectorDefinition`, `ConnectorInstance` and `Source` as separate stable identities, with
  multiple independently configured instances and Sources per connector type.
- Create, inspect, update, disable and tombstone-remove connector instances and Sources while
  retaining every existing Acquisition, Document, Version, provenance link and Original.
- Inspect the same connector inventory and health view through the application service, CLI,
  read-only API and EN/IT Browser.
- Authorize installed-app connectors with OAuth 2.0 and mandatory PKCE S256, exact redirect
  binding, short-lived state, explicit consent and least-privilege scopes. Reauthorization and
  revocation do not erase acquired knowledge.
- Fetch HTTP(S) only after the current Instance, connector and Source policy authorizes it. The
  guarded transport rejects unsafe schemes, ports and destinations; revalidates DNS and redirects;
  and bounds time, redirects, headers, framing, media types and body expansion.
- Preserve connector definitions, instances and Sources through backup, restore and portable
  Instance export/import.

## Manual web acquisition

One explicit local action acquires one canonical URL. A successful request
retains the exact response representation as a content-addressed immutable Original and records
canonical/final URL, retrieval time, media type, hash, Source, connector instance and Acquisition
provenance.

For supported HTML and plain-text representations, Provelume also creates a bounded deterministic
readable-text derivative. That derivative is separately identified and never replaces the
Original. Unsupported or unreadable web formats can still be acquired without inventing text.
Every successful replay keeps its own Acquisition evidence; identical bytes reuse the existing
Original and avoid a redundant canonical Version.

## Delivered implementation slices

- **0.7/S01 — Connector foundations:** provider-independent definitions, multi-instance identity,
  Source identity, external credential references and explicit network/origin policy.
- **0.7/S02 — Lifecycle and aligned views:** bounded instance/Source mutations, tombstones,
  secret-free operation evidence and shared service/CLI/API/Browser read models.
- **0.7/S03 — OAuth 2.0/PKCE:** installed-app request/callback, revocation and reauthorization
  boundaries with replay, mismatch, escalation and secret-leakage failures closed.
- **0.7/S04 — Guarded web transport:** Source-bound HTTP(S), SSRF and DNS-rebinding resistance,
  redirect revalidation, pinned approved addresses and bounded response handling.
- **0.7/S05 — Manual acquisition:** atomic one-URL acquisition, immutable Original retention,
  deterministic text derivation, exact-duplicate reuse and portable lifecycle qualification.

## Deliberately not included

`0.7.0` does not include automatic or scheduled refresh, watched folders, a filesystem watcher,
OCR, email or Google Drive intake, AI classification, semantic search, MCP, a Git mirror, Synology
deployment, a Windows background agent, Authenticode signing, unattended update application,
Provelume Cloud, accounts or billing. It does not delete or move provider content.

The Windows updater remains user-controlled: checks are disabled by default, downloading requires
an explicit action and applying an update requires confirmation through the normal unsigned
installer. The product remains local-first and works without GitHub at runtime, Provelume Cloud,
Nexus or an external AI provider.

## Compatibility and authority boundary

Connector state is additive to the schema-2 Portable Instance. Canonical readable JSON and exact
Originals remain authoritative; readable text, indexes, caches, views and the Markdown library
remain derived and rebuildable. Credentials remain outside canonical connector records, which may
retain only validated external environment or system-keyring references.

All network behavior remains declared, policy-gated, attributable and bounded. Disabled or local-
only policy performs no connector access and has no ambient fallback. Removing a Source, disabling
a connector, revoking authorization or observing provider disappearance never purges an acquired
Original.

The public clean-room boundary is unchanged. This release contains no private Nexus code, data,
paths, configuration, fixtures, prompts or history and introduces no Nexus build or runtime
dependency.

## Release evidence and exit gate

The exact reviewed candidate must pass:

- agent-protocol self-test, Ruff, the full pytest suite and `git diff --check`;
- trusted-base product change control, mergeability, required-review policy and zero unresolved
  review threads;
- clean-room and repository-hygiene checks;
- Ubuntu and Windows Core tests;
- deterministic wheel and source-distribution builds from independent clean source copies;
- a separately provisioned offline rebuild with byte comparison;
- offline wheel smoke tests, release-assurance validation and provider-independent release-bundle
  verification;
- Windows x64 installer construction, unsigned-signature assertion, default/custom installation,
  a real immutable public `0.6.1 → 0.7.0` in-place upgrade, exact Instance/settings preservation,
  startup and uninstall;
- agreement among package, `__version__`, embedded build identity, installer, update manifest,
  release plan, tag and source commit.

The immutable upgrade baseline is
`v0.6.1@087094210be8c0d3c8d2d5a32de3f981f6e8be20`. Its installer is
`Provelume-Setup-0.6.1-x64.exe`, size `18,344,455` bytes and SHA-256
