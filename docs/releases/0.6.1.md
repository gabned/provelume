# Provelume Core 0.6.1 release plan

This correction release consolidates the public `0.6.0` Portable Instance preview through
execution issue #102. Implementation and release preparation are complete. This document does
not itself create a tag or publish assets; those privileged actions remain restricted to the
permanent release workflow operating on the reviewed `main` result.

## Correction outcome

`0.6.1` adds no new product capability and makes no canonical Instance schema change. It closes
two bounded integrity defects discovered after `0.6.0` publication:

- permanent purge now removes bounded operational records linked through the selected Document's
  Version and Acquisition identities, preventing retained ingestion locators and dangling
  acquisition references after purge;
- filesystem ingestion, ingestion retry, their derived search-index refresh and Inbox ingestion
  now use the same cross-process Instance lifecycle lock as permanent purge, preventing canonical
  acquisition or index maintenance from racing purge staging, rollback and recovery.

## Compatibility and authority boundary

The schema-2 Instance manifest, canonical knowledge records, content-addressed Originals,
hierarchy, classifications, dispositions, Markdown library, portable export/import and existing
schema-1 to schema-2 migration retain their `0.6.0` contracts. No migration is added for an
already valid `0.6.0` Instance. Search indexes and the Markdown library remain disposable derived
state; acquired Originals and canonical records remain authoritative.

Purge still requires a fresh impact preview, short-lived confirmation token and explicit
acknowledgement of Source, backup and replica limits. Its authority remains bounded to the live
Instance and does not claim deletion from external Sources, backups or replicas. The local
Knowledge Browser remains a single-user loopback application without accounts, LAN or Internet
serving.

## Release evidence

The reviewed release candidate must pass:

- Ruff and the full test suite on Ubuntu and Windows;
- trusted-base change control plus clean-room and repository-hygiene checks;
- deterministic wheel and source-distribution comparison across independent clean source copies;
- offline rebuild, release-bundle verification, checksums, CycloneDX SBOM and attestations;
- regressions proving Acquisition-linked operational state is purged and every supported
  filesystem/Inbox ingestion path plus derived index refresh stays inside the lifecycle lock;
- Windows x64 installer build and a real upgrade from the immutable public `0.6.0` installer with
  stable AppId, exact current-schema Instance/settings preservation, loopback startup,
  Unicode/default paths and uninstall evidence;
- exact tag, package, embedded identity, public commit and preview-channel agreement.

The public baseline installer is `Provelume-Setup-0.6.0-x64.exe`, size `18,343,369` bytes and
SHA-256 `da338c65b8698d411561bbcb02e0711a1467628e3551c74b0989a7efe7ef6bc3` from
`v0.6.0@bc02180fa116c2924b04f0a4c0bcf497a1efbd70`.

## Explicit exclusions

This patch does not include a connector or network Source, a watcher, autonomous classification,
multi-master synchronization, OCR, AI, semantic/vector search, cloud storage, accounts/billing,
Authenticode, unattended update application, dependency maintenance or Agent Development Protocol
changes. It does not activate or begin `0.7.0`.
