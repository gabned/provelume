## Delivered slice — 0.9/S01

S01 establishes:

- a disabled-by-default local/offline OCR configuration and closed mode vocabulary;
- an optional replaceable adapter seam with Tesseract CLI 5.5.3 as the selected first baseline;
- public settings, capability, page result, provenance, idempotency and checkpoint records;
- explicit scanned-PDF/TIFF/PNG/JPEG/BMP input and hostile-input/resource ceilings;
- English/Italian absence messages with no download, cloud or remote fallback;
- engine, Leptonica, language-pack and future codec licensing/redistribution gates;
- wheel, sdist and Windows optional-component behavior with no OCR binary shipped in S01;
- automatic tests and synthetic hostile/boundary fixtures.

S01 does not implement or advertise a working OCR pipeline.

## Stable invariants

- Originals and canonical knowledge remain authoritative and unchanged.
- OCR text, coordinates, confidence, warnings and supported observations are derived, removable,
  rebuildable and bound to exact page provenance.
- Machine recognition is never presented as verified text.
- Layout, table, barcode and QR observations remain separate from text and exist only when a
  declared adapter produces them.
- Disabled and unavailable states perform no network access, component download or provider
  fallback.
- Future execution reuses Vigilia's leases, heartbeat, committed checkpoints, recovery and terminal
  receipts without hiding content in the journal.

## Later Lectio sequencing

The next forecast-only slice, `0.9/S02`, may implement the bounded local OCR page renderer,
Tesseract process adapter, derived persistence and document-bundle path. It is not activated: no
S02 issue, branch or owner PR was created by S01.

Email/mailbox, Google file and transcript intake remain later Lectio forecast scope to decompose
just in time. Cross-source qualification, Action Center, AI, RAG, vision/remote OCR and every
`0.10+` capability are outside this development record.

## Release boundary

No S01 commit creates a tag, release or asset and no S01 change moves package, `__version__`,
embedded build identity, installer or updater metadata to `0.9.0`. A later explicitly authorized
release-preparation PR must align every identity and complete the exact release qualification
before any immutable tag or public release can exist.
