# 0037 — Explicit editorial examples for bounded synthesis

Status: candidate selected before scoring, 2026-10-09. Same maintainer-authorized
S08 profile revision and sole PR #333 owner. Not Recommended or release authority.

## Evidence and decision

ADR 0036's single-inference paragraph decisions still fail semantic selection:
Windows scores 18/32 correct and 7/8 required abstentions; Linux 16/32 and 6/8.
Both have 32/32 valid references and pass all 19 inherited gates and S08 performance.
The complete 15-run inventory has 53 jobs, with only the native workflow
failing. Those failures remain failures. No format guarantee proves useful output.

The recurring errors confuse editorial boilerplate or assistant-directed commands
with document subject matter. Keep the same model, quantization, non-thinking
template, sampler, single inference and complete KEEP/DROP subset grammar. Make
the editorial policy concrete with four small, fixed English/Italian examples:
equipment facts and practical directions beside a draft label; an attempted answer
override beside a conditional maintenance fact; an empty formatting placeholder;
and two contradictory reports about a bridge. The examples are public instructional
material, independent of the frozen evaluation's text, entities, indexes and gold.
They contain no predicate or phrase filter applied to the actual source.

The examples enter only the trusted native system instruction. The actual approved
source remains solely in the user message; all decisions address only its original
positions. Every legal subset remains available and each KEEP translates losslessly
to its exact index. There is no post-filter, second inference, automatic retry or
selection of a best sample. Providers retain the existing canonical JSON contract.

Profile `extractive-decisions-v3` and the digest of the complete native instruction
for each task maximum bind runtime configuration and template/consent identity.
Changing even an example invalidates old bindings without relying solely on a
manually changed version label. The complete rendered native frame is also refused
before sampling if it exceeds the unchanged 4,096-byte input ceiling. A synthetic
boundary test admits 16 paragraphs totalling 2,000 source bytes, proves the examples
remain outside the source, and quotes only a real source index. It does not score
model quality.
