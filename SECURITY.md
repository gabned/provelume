# Security policy

Provelume handles private knowledge and source material, so security and provenance failures are treated as product-critical issues.

Please do not publish exploitable vulnerabilities, credentials, private source content or tenant data in a public issue.

When GitHub private vulnerability reporting is enabled for this repository, use the repository Security tab. Until then, use the private security/contact channel published on https://provelume.com.

Supported-version policy will be published before the first stable release.
